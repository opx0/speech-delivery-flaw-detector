## What the product does

It compares a speech with a gold-standard delivery of the same text and pinpoints where and why
the delivery deviates, with timestamps, the quoted words and the acoustic cause. Two modes.

- **Contrast.** The transcript matches a library text. The participant is compared with the gold
  clip, word by word.
- **Normative.** The transcript is not in the library. The participant is compared with p10 to
  p90 bands learned from the gold and natural-reader clips. Findings are marked lower confidence.

Four delivery axes are scored 0 to 100: cadence, tone, pauses, volume. Content is out of scope.
Scoring is deterministic. There is no neural model beyond the CTC forced aligner.

## Decisions already made (do not reopen)

- Six flaw kinds in `contract/taxonomy.py`. `FLAW_SPECS` is the one table that says which axis
  and feature judge each kind. Read it.
- Each flaw has severity levels 1 to 4 (4 is the worst). Level 0 is a control: the clean gold
  clip put through the same resynthesis path with neutral parameters.
- A flawed clip carries 2 to 4 flaw regions, snapped to word boundaries. Ground truth is known by
  construction, in the flawed clip's own clock.
- Evidence is computed per 10 ms frame (`analysis/constants.py`), smoothed over 250 ms, then
  snapped to word boundaries. A flagged region is at least 0.5 s long and quotes its words.
- Pitch is in semitones relative to the speaker's own median. Energy is in dB relative to the
  speaker's 95th percentile of speech frames. That is what makes the comparison speaker-agnostic.
- Deterministic everywhere. Fixed seeds, no wall clock, no unordered iteration in outputs.
  Same input must give byte-identical output on repeated runs.
- Public-domain sources only. No TED.

## Interfaces between workers

Each worker implements its side exactly. Import the others by these signatures even if they are
not written yet. In tests use fakes or synthetic objects, never the other worker's code.

```python
# analysis/align.py (signal worker)
def align(audio: Audio, transcript: str) -> WordAlignment: ...
# raises AnalysisError(ErrorCode.ALIGNMENT_FAILED, ...) when the text cannot be aligned.

# analysis/features.py (signal worker)
def extract_features(audio: Audio, alignment: WordAlignment) -> RecordingFeatures: ...

# analysis/signal.py (signal worker)
def analyze_signal(audio: Audio, transcript: str) -> Recording: ...

# analysis/calibration.py (compare worker)
class Calibration: ...            # frozen, JSON round-trip, carries a `version` string
def build_calibration(library: Library, recordings: Mapping[str, Recording]) -> Calibration: ...
def save_calibration(calibration: Calibration, path: Path) -> None: ...
def load_calibration(path: Path) -> Calibration: ...

# analysis/compare.py (compare worker)
@dataclass(frozen=True) class Findings:
    regions: tuple[FlawRegion, ...]
    axis_scores: tuple[AxisScore, ...]
    overall: float
    overlay: tuple[OverlaySeries, ...]
    reference: BaselineReference | BandReference
def compare_to_baseline(participant: Recording, baseline: Recording, text_id: str,
    baseline_clip_id: str, calibration: Calibration, weights: RubricWeights) -> Findings: ...
def compare_to_bands(participant: Recording, calibration: Calibration,
    weights: RubricWeights) -> Findings: ...

# analysis/analyzer.py (compare worker)
def build_analyzer(library: Library, calibration: Calibration) -> Analyzer: ...

# dataset/inject.py (injector worker)
@dataclass(frozen=True) class Injected:
    audio: Audio
    alignment: WordAlignment        # in the new clip's clock, exact by construction
    flaws: tuple[FlawLabel, ...]    # empty for control and speaker-shifted clips
def make_flawed(audio, alignment, kinds: tuple[FlawKind, ...], level: int, seed: int) -> Injected
def make_control(audio, alignment) -> Injected
def make_speaker_shifted(audio, alignment, semitones: float, formant_ratio: float) -> Injected

# api/app.py (api worker)
def create_app(library: Library, analyzer: Analyzer, web_dist: Path | None = None) -> FastAPI
```

HTTP surface (api worker implements, web worker consumes). Bodies are the contract types.

- `GET /api/library` returns `LibraryListing`.
- `GET /api/audio/{clip_id}` streams a FLAC with range support. Only gold, control and flawed
  demo clips are served. Human held-out clips are never served. Unknown id returns 404.
- `POST /api/jobs` is multipart: `audio` (file) and `options` (JSON string of `AnalyzeOptions`).
  Returns `JobCreated`. Oversize returns 413. Not valid JSON options returns 422.
- `GET /api/jobs/{job_id}/events` is Server-Sent Events. Each `data:` line is one `JobEvent`
  JSON. Late subscribers get every earlier event replayed. The stream closes after `done` or
  `failed`.
- Everything else serves `web/dist` with single-page-app fallback when it exists.
